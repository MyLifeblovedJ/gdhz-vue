# Home Map Toolbar Split Design

> 日期：2026-03-17
> 范围：`apps/gdhz-vue-2999`

## 目标

- 将风浪潮首页右侧纵向工具栏拆分为“右侧竖向入口 + 右下横向操作区”
- 右侧竖向仅保留：`图层`、`观测设备`、`AI`
- 右下操作区参考 Windy 的横向组织方式，分两行展示地图操作和专题开关
- 在操作区底部增加海浪横向图例，避免现有图例信息分散

## 已确认的按钮映射

- 右侧竖栏：`图层`、`观测设备`、`AI`
- 第一行：`放大`、`缩小`、`3D/2D`、`重置视角`、`底图切换`、`台风`、`全屏`
- 第二行：`摄像头`、`船舶`、`风速`、`温度`、`降水`、`海平面气压`、`地形`
- `定位` 不再单列，归并为 `重置视角`
- 原“关于这些数据”位置改为 `底图切换`

## 交互结论

- `放大`、`缩小`、`3D/2D`、`重置视角`、`底图切换`、`台风` 复用现有事件和状态
- `全屏` 新增浏览器 Fullscreen API 切换
- `摄像头` 复用现有海岸观测覆盖开关
- `船舶` 绑定 `store.layerVisibility.vessels`
- `风速` 绑定 `store.layerVisibility.wind_particle`
- `温度`、`降水`、`海平面气压`、`地形` 当前无完整地图渲染链路，先以禁用态展示，不伪装成可用功能

## 组件结构

- `MapToolRail.vue`：只保留竖向主入口，不再承担地图操作区布局
- `MapActionDock.vue`：新增右下横向操作区组件，承载两行按钮和海浪横向图例
- `SeaConditionHome.vue`：负责接线、状态透传、全屏逻辑和专题图层切换

## 验收标准

- 右侧竖栏只出现 3 个入口按钮
- 右下操作区按约定顺序出现两行按钮
- `船舶`、`风速`、`摄像头`、`台风`、`3D/2D`、`底图切换`、`重置视角` 可触发对应行为
- `温度`、`降水`、`海平面气压`、`地形` 为明确禁用态
- 海浪横向图例固定显示在右下操作区底部
