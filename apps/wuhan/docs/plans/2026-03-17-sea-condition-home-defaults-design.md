# 风浪潮首页默认态调整 Design

**目标**

将 `apps/gdhz-vue-2999` 的风浪潮页面默认展示切换到更接近业务演示需求的状态：默认 `2D`、仅显示风暴潮核定站与海岸观测站、海岸观测小窗使用站点图片、底部信息改为相对时间、在线状态改为名称前状态点。

**范围**

- 仅调整 `apps/gdhz-vue-2999`
- 不改旧目录 `gdhz-vue`
- 不改地图底层渲染逻辑，只调整风浪潮页默认参数和海岸观测展示

**设计**

1. 默认进入风浪潮页时，地图模式使用 `2D`。
2. 页面初始化图层时仅保留 `surge_stations` 与 `erosion_monitor`，将 `coastal_base`、`tide_stations` 关闭。
3. 地图上的海岸观测小窗复用右侧海岸观测图片资源 `/images/coastal/<id>.png`，避免继续使用模拟视频画面。
4. 小窗底部文案保留站名与相对更新时间，显示“刚刚”“1分钟前”等，不再显示侵蚀速率与风险颜色条。
5. 站点名称前增加状态点：在线为绿色，离线为灰色；离线站卡片整体弱化但继续展示图片。

**测试策略**

- 更新默认地图模式测试，先验证旧行为失败，再改为 `2D`
- 为风浪潮页新增默认图层源码测试，锁定 `coastal_base: false` 与 `tide_stations: false`
- 为海岸观测小窗新增源码测试，锁定图片渲染、状态点、移除风险条与侵蚀速率
- 为相对时间新增纯函数测试，覆盖“刚刚”“1分钟前”“59分钟前”等
