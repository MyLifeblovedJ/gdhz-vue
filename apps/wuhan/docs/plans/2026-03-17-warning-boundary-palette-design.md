# 预警边界与省界配色优化 Design

**目标**

在不改变“城市预警边界发光”表达方式的前提下，进一步拉开橙色与黄色预警的区分度，并将广东省边界调整为在深浅底图下都稳定可读、且不与黄色预警冲突的颜色。

**范围**

- 仅调整 `apps/gdhz-vue-2999`
- 同时影响 `2D/3D`
- 不改预警数据来源、预警层级或省界线宽

**设计**

1. 橙色预警改为更深的琥珀橙：`#FF8A3D`
2. 黄色预警改为更干净的金黄：`#FFD84A`
3. 红色与蓝色预警保持不变，维持现有识别惯性
4. 广东省边界改为中性白蓝：`#CFE8FF`
5. 省界仍保持高层级与清晰线宽，但避免与黄色预警撞色

**测试策略**

- 在 `MapContainer.test.js` 锁定新的橙色、黄色与省界颜色常量
- 保持现有 glow 边界测试继续通过
