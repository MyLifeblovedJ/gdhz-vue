# 头部整体下拉导航设计

## 背景

当前头部二级导航已经支持统一展示所有子菜单，但呈现方式仍然是“在 header 下方拼接一个面板”。这会带来两个问题：

- 高级感不足，结构上仍然像额外叠加的悬浮层
- 各一级栏目和子菜单列对齐不稳定，容易出现视觉错位

新的目标是把二级导航改成“整个 header 从中间导航触发后整体向下展开”，并在展开时对 header 之外的页面区域施加毛玻璃虚化，形成更完整的导航沉浸态。

## 目标

- 鼠标移入中间导航区时，整个 header 往下展开
- 二级菜单成为 header 的下半部分，而不是独立浮层
- 展开时 header 之外的页面内容弱化并毛玻璃虚化
- 所有一级栏目列严格顶对齐，子菜单竖向整齐排列
- 保留现有二级菜单占位跳转逻辑

## 方案

### 1. 头部整体展开

`AppHeader.vue` 从固定单层 header 改为双层结构：

- 顶层：品牌、一级导航、时间天气
- 展开层：统一的二级导航内容区

默认状态下只显示顶层。移入中间导航区后，header 高度扩展，展开层显示。

### 2. 二级菜单对齐

展开层使用固定列网格，不再让内容自由流动：

- 每列一个一级栏目
- 栏目标题固定在列顶
- 子菜单在标题下竖向排列
- 列顺序严格跟随导航配置顺序

这样可以避免“风浪潮下面接海啸”这类错位问题。

### 3. 页面背景虚化

在 `App.vue` 增加一个全局背景遮罩层：

- header 展开时显示
- 遮罩位于 header 下方、页面内容上方
- 使用半透明浅色叠层和 `backdrop-filter: blur(...)`

这层遮罩不盖住 header，本质是把 header 以下的页面内容压暗、降噪、虚化，让用户聚焦在导航上。

## 交互

- 触发：鼠标移入中间导航区
- 保持展开：鼠标在导航区和展开后的 header 区域内移动
- 收起：鼠标离开整个 header 展开区域
- 展开时机：仅由中间导航区触发，不因移入品牌区或右侧天气时间而展开

## 动画

- header 高度扩展：220-280ms
- 背景毛玻璃遮罩：同步淡入
- 二级菜单列内容：轻微延迟淡入

整体表现应接近“顶部导航抽屉”而不是“弹层菜单”。

## 影响范围

- `src/components/layout/AppHeader.vue`
- `src/App.vue`
- `src/components/layout/AppHeader.test.js`
- 可能新增 `src/App.test.js`

## 风险控制

- 遮罩只作用于 header 以下区域，避免盖住导航本身
- 使用固定展开高度，避免因子菜单多少不同导致 header 高度跳变
- 仅改展示层，不改现有路由与 submenu query 跳转逻辑
